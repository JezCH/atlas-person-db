# YouTube content gate – prevent forged original video metadata (2026-10-17)

## WHY THIS UNIT

The only final product remains ONE verified **unregistered historical Person** ranked source list: independently accumulated original YouTube Video IDs/Channel IDs, actual individual-focused video playback/timestamped transcript evidence, reviewed same-Person multilingual alias original-ID unions, ATLAS registered-person exclusion LAST, governed publish and public Runtime/UI readback. This content gate is an intermediate **offline read-only** evidence validator, not a second Person ranking or a substitute for verified actual content.

The original `scripts/youtube-source-video-content-evidence-gate.py` checked source artifact SHA string and for *one positively reviewed video* its Channel ID/status. It did **not** recheck the metadata row's `original_title`, `description_sha256`, `person_video_content_verified=false`, the global `automatic_person_subject_approval=false`, `requested_original_video_ids`, or agreement of status with actual channel/description. Adversarially edited metadata could therefore cross the positive review gate if a copied Video ID and Channel ID still matched.

## FIXED, TESTED – NOT PRODUCTION

- `validate_collected_metadata` runs **before adjudication** and independently binds *every available snippet* to the immutable original Video ID + Channel ID + original title, source snapshot, source review SHA, and ZIP SHA. Checks the UTF-8 description SHA256, collector's exact status derivation, false person approval flags, no duplicate/foreign IDs, and precise fetched/unfetched population. An unavailable-video result cannot simultaneously carry live title, publication date or description. Exact original Channel ID status mismatch refuses a positive review.
- Source original population duplicates are now explicitly detected before dictionary construction, and a forged decision source ZIP SHA (when provided) cannot be silently accepted.
- The existing evidence method contract still requires **explicit human reviewer, observed 10+ second clip or timestamped transcript, timestamp and per-video YouTube source URL**; mere title/public publisher description still cannot certify actual video subject. Positive fixtures in tests are synthetic, **0 actual B024 original videos were content-certified**.
- Added a fifth Python unit to `tests/test_youtube_video_description_content_gate.py` and updated the existing node test wrapper to assert five tests. Adversarial cases: substituted original title/channel, tampered description/digest, fake auto person approval, inconsistent status/channel, false fetched/unfetched count, foreign source review SHA, duplicate Video ID, unavailable-video publisher metadata leak, plus authorized partial collection positive and missing-video refusal.
