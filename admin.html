중복 후보 검토

이름은 후보를 찾는 근거일 뿐 identity가 아닙니다. 후보마다 근거와 신뢰도를 보고 병합 승인, 별개 인물, 추가 검토를 기록합니다. 병합 승인은 여기서 인물을 삭제하지 않습니다.

현재 병합 실행 경계

MERGE 판정과 실제 병합은 분리됩니다. 실제 physical Person 병합은 서버가 현재 semantic-key v2 reconciliation, 전체 duplicate revalidation frontier, durable requirement, live evidence와 참조 표면을 모두 다시 검증해 merge_execution_state.allowed=true일 때만 제공됩니다. 실행 시 유지할 Person UUID와 관계 정리 방식을 명시한 하나의 PostgreSQL SERIALIZABLE transaction으로 처리하고, 병합 후 후보 frontier를 같은 transaction에서 다시 계산합니다.

Identity authoring 준비됨

활동 관계 JSON 입력

먼저 위에서 필요한 identity를 만든 뒤 활동 관계를 저장합니다. 동일 활동 판정은 Person + Polity + Relation + Role/NULL + Period basis + 전체 시작/종료 temporal boundary를 사용합니다. 역사 연도 0은 허용하지 않습니다.
