# ATLAS 한국어 UI 전면 현지화 — 전체 목표·종결 계획

**상태: 진행 중.** 이 문서는 완료 조건과 다음 재개점을 보존하는 작업 계획이며, 운영 배포 상태나 GitHub `main`을 대신하는 원본은 아닙니다.

## 1. 최종 목표

현재 `main`에서 **사용자에게 실제로 노출되는 모든 UI 문구**를 자연스러운 한국어로 통일한다. 제목, 버튼, 메뉴, 상태, 표 머리말, 설명, 도움말, 입력 안내, 오류, 로딩/빈 목록, 도구 설명 및 접근성(ARIA)을 모두 포함한다. 정적 HTML뿐 아니라 **API에서 내려온 동적 상태값·분류 코드가 화면에 직접 출력되는 경우**도 검토한다.

**화면 범위:** 대시보드 / 인물 목록·상세·편집 / 시공간 인물도 / 정치체 목록·검토 / 장소·사건·출처·지리 형상의 준비 상태 / 인물 등록검토 및 YouTube 발굴 / 관리자 인증·정보조회·관리 기능 / 모바일 대응 화면.

## 2. 절대 보존할 경계

- 사용자가 보는 표시 문구만 수정한다. 기존 Person, Activity, Polity, Source 등 역사 데이터나 관계를 번역 목적으로 바꾸지 않는다.
- UUID, 데이터베이스 값, API·JSON 키, 상태 코드, URL 라우팅, 관리자 선택 항목의 `value`, 테스트가 검증하는 실제 기능 계약은 그대로 둔다.
- 역사적 고유명사·검증된 표제어, 외부 서비스명, API/DB 식별자 및 의미 있는 등급 기호(S/SS/SSS 등)는 임의로 번역하지 않는다. **그에 붙는 사용자용 설명은 한국어**로 제공한다.
- 모르는 내부 코드에는 근거 없는 번역을 만들지 않는다. 한국어 `확인 필요` 표시와 원본 데이터 보존을 병행한다.
- 사용자 오류 메시지는 한국어 복구 안내로 제공하고, 원본 오류 진단은 개발 로그에 남긴다.
- 검색/정렬/필터·접근성·모바일 사용성이 한국어 표시 전환으로 훼손되지 않게 한다.

## 4. 남은 전체 실행 계획

1. **정적 문구 전수조사:** 실제 진입점과 동적으로 로드되는 사용자 화면에서 영어 제목·텍스트·버튼·상태·placeholder·ARIA 등을 색인화하고 예외를 분류한다.
2. **동적 표기 전수조사:** API 기반 enum/상태/역할/신뢰도/검토 결과/오류가 단순 코드 그대로 노출되는 곳을 식별한다. 표시 레이어에서만 번역한다.
3. **화면별 수정:** 대시보드 → 인물·상세 → 시공간표 → 정치체 → 장소/사건/출처/지리 형상 → 등록 검토 → 관리자 전체를 빠짐없이 종결한다. 선후 순서는 실제 발견 이슈와 충돌 범위에 맞춰 조정 가능하다.
4. **상태·접근성 검증:** 정상/로딩/빈 데이터/네트워크 실패/권한 거부/미등록 값 등과 모바일·데스크톱, 도구 설명, 검색·정렬·필터를 검사한다.
5. **회귀·CI:** 화면별 집중 테스트 + ATLAS Integrity. 기존 영어 테스트 문자열만 기계적으로 치환하지 않고 본래 기능 불변을 검증한다.
6. **Production 최종 승인:** 실제 운영 배포 커밋과 `main` 비교 후 대표 화면을 브라우저에서 점검한다. 원문 노출 0건 또는 **근거가 기록된 예외만** 남아야 종결이다.

## 5. 운영 규칙과 정확한 재개점

`WORK_EXECUTION.md`에 따라 현재 경로의 변경 차이만 확인하고, 한 번에 종결 가능한 작업 단위 하나를 **수정 → 테스트 → PR/CI → 병합 → 검증 → 보고**까지 끝낸 후 턴을 닫는다. 불필요한 전역 재감사, 무의미한 재배포, 다른 작업 축 재개는 금지한다.

**등록검토 화면 단위 종료 후 다음 정확한 재개점:** 대시보드·인물·시공간표·정치체·관리자에서 **API 제공 영어 상태/오류가 실제로 표시되는 지점**을 현행 `main` 기준으로 추적해, 충돌하지 않는 가장 작은 다음 UI 수정 단위를 선택한다. 전체 남은 범위와 완료 기준은 이 문서를 계승한다.
