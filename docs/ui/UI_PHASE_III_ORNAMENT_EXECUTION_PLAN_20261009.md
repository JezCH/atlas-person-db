> **상태:** PROPOSED / 설계안 확정 전 · 2026-10-09
>

>
> **설계 키워드:** Grand Atlas × Chronometer × Illuminated Codex — **고지도·천문기구·장식 필사본**
>
> **규범:** [Phase III 장식 레퍼런스 보드](UI_PHASE_III_ORNAMENT_REFERENCE_BOARD_20261009.md)의 후보 42개 중 **P0 19개를 우선 시안 대상**으로 선정하되, 실제 채택은 화면별 A/B 비교 후 결정한다.

> **Phase II 현황:** VIS2-00~13 완료 및 Production exact-SHA 검증 PASS. 해당 통과는 기능·회귀 안정성의 증거이며 사용자가 요구하는 **장식적 미감의 완성** 판정과는 별개이다.
>
> **개발 경계:** 이 문서는 구현 착수 승인이나 기존 `ATLAS_UI_VISUAL_GUIDELINES.md` 변경을 의미하지 않는다. Canonical 지침 개정은 시안 승인 이후 별도 PR로 처리한다.

## 1. 목표·배경·성공 판정

Phase I/II는 밀도, 정렬, 색채, 서체, 절제된 선과 프레임, 상호작용의 안정성을 개선했다. 그러나 현재 Production은 사용자가 지속적으로 요청한 **눈에 띄는 장식적 역사성**, 제국적/기념비적 개막부, 시공간 측정기구의 물체성, 인물 전기 도록의 장중함이 부족하다. **그라파이트 배경과 샴페인 금속선을 한 겹 더하는 방식은 Phase III로 인정하지 않는다.**

1. **상징적 정체성:** 처음 5초 관찰에서 일반 관리 UI와 명확히 다른 **역사 아틀라스**의 장식 구조를 확인할 수 있어야 한다.
2. **실재하는 조형 문법:** 고지도 카르투슈/에칭, 세밀한 아스트롤라베 눈금, 필사본 장식 머리글자·판각, 문화권별 문양의 역사적 형태에서 영감을 얻되 물증 없이 사실·왕실 문장·신분을 위조하지 않는다.
3. **과감하되 선택적:** 큰 섹션 시작·인물/정치체 상세 입구·시공간 외측 도구 프레임에서는 분명히 장식적이다. 반복 인물 행·활동 트랙·출처 텍스트 안쪽에서는 높은 밀도와 원 데이터가 주연이다.
4. **문화권의 독립성:** 공통 인터페이스는 중립적인 기하학적 아틀라스/천문기구 문법; 지역별 표제 장식은 해당 시대·지역의 실제 시각 유산을 참고. 유럽 왕관/로렐을 전체 문명사에 무분별하게 씌우지 않는다.
5. **속도·접근성:** 장식 때문에 검색·정렬·포커스·패닝·줌·반응형·모바일 터치·reduced-motion·출처 표기가 악화되면 채택하지 않는다.

**핵심 디자인 명제:** '데이터를 조금 꾸민 시스템'이 아닌 **'정교한 역사적 장식물이면서 실제로 탐색할 수 있는 정보 도구'**를 만든다.

## 4. 공통 자산과 기존 스타일 중복 회피

- 이미 있는 `atlas-ui-visual-foundation.css`의 `--atlas-honor-metal` 및 표면 토큰, `atlas-person-spacetime-instrument-tools.css`, `atlas-person-spacetime-precision-ticks-v2.css`, `atlas-person-monumental-register.css`, `atlas-person-chronicle-detail.css`, `atlas-vis2-11-polity-dashboard-archive.css`를 먼저 확인하고 소유권을 침범하지 않는다.
- 새 스타일은 비주얼 콘셉트 승인 후 하나의 버전/토큰 소스 + 조형 자산 + 화면 한정 로더를 원칙으로 한다. CSS 파일을 단위마다 쌓아 특정성 전쟁을 만들지 않는다.
- 기존 VIS2-05의 **실험 워터마크 = REJECT / 기본 OFF**는 별도 시안 승인 없이는 재활성화하지 않는다.
- 도구 조형/스탬프/메달의 **가상 의미를 데이터나 사실처럼 표현하지 않는다**. 눈금이 진짜 시간축 눈금이면 원래 좌표만 미화하고, 장식선이면 별도 `aria-hidden` 순수 표현을 유지한다.
- 이미지 자산은 SVG/비트맵 복사보다 **직접 제작한 추상 세공 문양**이 기본. 역사 유물 이미지 사용은 유물 단위 권리와 출처 확인 후.
- 새 UI 데이터 필드나 서버/DB 엔드포인트는 구현하지 않는다.

## 6. 스크린샷 시안 제작 상세 규칙

**비교 장면 고정**: 동일한 Production 원본 DOM/실제 데이터/폰트/viewport로 ① 기존 Phase II ② A 원화형 ③ B 기계형 ④ C 필사본형 ⑤ A+B+C 권장 혼합안 제작.

- **대시보드**: 1440px 전체 첫 화면 + KPI/검색 조작중 390px. 기존 KPI 같은 숫자, 동일 클릭가능 요소.
- **시공간표**: 1440px 500%, 1600px 1000/1500% East Asia/Europe 각각. 원본 연도/라벨/트랙 픽셀을 보존하고 도구 영역 디자인을 바꾼다.
- **Person Detail**: 실제 초상 존재 / 실제 초상 없음 / 장문 한글·라틴 이름 / 복수 Activity + Evidence 펼침 / 출처 없는 경우.
- **Person Main**: 390/1440 시대 경계, 선택 인물, 필터·정렬 조작, 다분야 색상 및 거대한 인물수.
- **Polity**: 390/1440 실제 designation/governance/source 내용이 있는 상세.
- **공통**: 화면 배율 125%/150% 상당 CSS viewport & DPR, keyboard-only focus, touch pointers, reduced-motion.

**시안의 질적 심사 (각 항목 1~5점, 디자인팀 내부 제안 점수표):**

| 항목 | 가중치 | 실무 판단 |
| --- | ---: | --- |
| 처음 보는 사람이 느끼는 문명 아틀라스 고유의 정체성 | 25% | 일반 어드민 템플릿과 구별되는가 |
| 장식의 실제 존재감과 조형적 완성도 | **30%** | 일러스트/세공/카르투슈가 분명하게 보이는가 |
| 역사적 타당성과 문화권 존중 | 15% | 위조 문장/허위 자료/문화권 오용이 없는가 |
| 콘텐츠 위계·인물표/연대표 판독성 | 20% | 실제 역사 정보가 우선적으로 읽히는가 |
| 모바일·사용성의 심미적 일관성 | 10% | 반응형 전환에서 장식이 망가지지 않는가 |

계량점수만으로 자동 채택하지 않는다. **사용자 육안 승인이 필수**, 기능/접근성의 필수 불변 조건은 가중치와 별개의 탈락 조건이다. 한 화면에서 차이가 거의 없으면 Phase III 완료 판정을 내리지 않는다.

## 7. Acceptance / regression / performance 게이트

### 기능 불변 (정량)
1. Person main **열·행·정렬·필터·검색·선택·밀도**, 모든 기존 row geometry 유지.
2. Person 대표 8 분야 의미색과 현재 세부 레벨 분류 그대로. 공용 황동장식이 `governance` Gold의 의미를 지우지 않아야 한다.
3. Spacetime **카메라 500~1500%, X/Y unified, 공통 compression 0.748, 9 macroregion, axis 140px**, 시간투영/LOD/캡처 상태 불변.
4. 역사 데이터, Person/Activity/Polity UUID, 출처, 초상 provenance, BC/AD/불명 표기 불변.
5. 390/768/1440/1600px에 추가 가로 스크롤/정보 잘림 없어야 하고, 125/150% 실효 배율에서 터치·키보드 조작 가능.
6. 포커스 링 표시, 대비 최소 WCAG AA(일반 텍스트 4.5:1, 큰 텍스트/의미 그래픽은 적합한 3:1 기준 등), reduced-motion, 눈금·배지 장식 접근성 가림 없음.
7. 신규 장식 자산 전송 크기·초기 로딩·상호작용 지연은 VIS3-00과 비교해 계량 보고하고, 기능저하 원인이면 최적화 또는 미채택.

### 시각 승인 (질적)
1. 초기 화면에서 **카르투슈/중앙 장식/천문 링/장식 표제** 등 최소 2개의 명확한 시그니처가 별도 설명 없이 보인다. 모바일은 공간에 맞게 1개 대표 시그니처 허용.
2. 기존 섹션과 새 조형의 명암/서체/재질이 통일되며, 세공 문양이 반복 인물 행이나 실제 지도/연대 정보처럼 해석되지 않는다.
3. 브라우저 실제 Production 동일 데이터 전/후 스크린샷을 제공하며 선택된 차이가 실질적으로 보인다. **‘픽셀 차이 0’이면 디자인 성과로 인정하지 않는다.**
4. 한 화면씩 승인/보류/거절 가능하고 이전 스타일 롤백 가능하다. 시안 거절 시 구버전 유지, 기존 안정적인 UI 유지.

### 완료 정의
- 각 기능 PR: 디자인 승인 근거, 수정 파일/소유권 명세, current-Production A/B, regression CI, exact-SHA Chrome 결과, 실기기/에뮬레이션 모바일 확인, PR/문서 체크포인트.
- 전체 Phase III: 본질적 장식 고급화 인정, 기능 불변 검증, 사용자 시각 승인, 종결 문서와 증거 파일.

## 8. 우선순위, 실행 통제, 제외 범위

**최초 차별화가 큰 작업:** ① 공통 표제/대시보드 ② 시공간 기구형 프레임 ③ 인물상세의 실초상/장식 전기 ④ 정치체 ⑤ 인물표 시대 헤더 ⑥ 모바일. 메인 인물표 전체 재구성을 처음부터 시도하지 않는다.

**별도 유지/보류:** POLITY #1895와 UI 데이터 완결성 #1896은 다른 범위. 후보 등록/Polity Identity 처리, Admin 데이터 수정, P14 Territory/Geometry는 이 디자인 계획에 포함되지 않는다. 대량 AI 초상 생성도 여전히 사용자 보류.

**병렬성:** A/B/C 기초 디자인 시안은 독립적으로 제작할 수 있으나, 실제 shared style 토큰/루트 CSS 변경은 충돌하는 PR끼리 자동 병합하지 않는다. 현재 main과 리소스 소유권 preflight 후 좁은 단위만 merge, 한 번의 목적 적합 Production 검증을 원칙으로 한다.

## 9. 첫 실행 단위 VIS3-00 명령

> Production 최신 SHA와 Phase II 시각 기준 증거를 읽고 동일 DOM 기반 최종 6개 화면 집합(대시보드/인물표/인물 상세/활동·출처/정치체/시공간표)의 390·1440 및 핵심 768/1600 상태 캡처를 수집한다. 기존 CSS 소유권 및 UI 고급화 제약을 적고, 우선 보이는 장식의 부족함을 스크린샷에서 구체적으로 표시한다. **디자인 구현이나 canonical 지침 수정은 시작하지 않는다.** 한 단위가 끝나면 사용자에게 실제 비교 근거와 남은 문제를 보고하고 중단한다.
