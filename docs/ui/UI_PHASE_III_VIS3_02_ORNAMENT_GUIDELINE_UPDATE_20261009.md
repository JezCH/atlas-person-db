## Decision

The user repeatedly requested visible historical ornaments and directed continuation after VIS3-01 concept comparison. They have not selected one exclusive A/B/C style, so the previous recommended **screen-specific A+B+C hybrid** is adopted **as a working implementation guideline, not pixel-perfect aesthetic acceptance**.

- **A Grand Atlas** for shared entry/Dashboard/Polity title and epoch register transitions.

- **C Illuminated Codex** for Person Detail, genuine portrait frame, biographies and source cataloguing.

## What was corrected

- v1.0's **Frame ornament ★** universal ceiling has been replaced with **★★★★** deliberate ornament for principal chapter cartouches, Spacetime instrument chrome and Person Detail folio/real portrait.
- v1.0's assertion that chronology itself replaces additional ornament was removed. Historical chronology is essential, but **conspicuous ornamental object forms are equally legitimate** outside actual plotted data.
- A display-shell chapter engraving is explicitly **not** the prohibited fabricated history/portrait illustration in Person main.
- New screen-by-screen allocation table and acceptance rules require unmistakable visual difference compared to identical Production content, not just thinner/brighter lines.
- Safeguards intact: dense Person geometry, 8 domain semantic colors, 500–1500% Spacetime unified X/Y and 0.748 / 9 regions / 140px axis, source provenance, portrait authenticity, mobile focus and keyboard, cultural context and artifact usage rights.
- Original VIS2-05 watermark **OFF**, user-parked P14 Geometry **still parked**.
