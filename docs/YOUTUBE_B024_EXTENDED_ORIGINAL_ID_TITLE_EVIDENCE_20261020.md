## 발견된 중요한 오류와 보완

제목에서 `Biography`·`Profile` 같은 단어가 쓰였더라도 이름 표기에는 `Black Holes`, `Pink Floyd`, `Hagia Sophia`, `12 Years a Slave` 같은 **실제 사람이 아닌 대상**이 있었음. `Prince Charles`, `Princess Alice`처럼 **복수 실존인물에 걸친 동명이인 문제**도 별도로 존재함.

이를 무시한 채 전수 후보를 최종 역사인물 순위로 만들지 않고, 독립 검토한 **비개인 명칭 52개 + 동일인/실존 정체성 불명확 10개 = 총 62개 원본 이름 표기를 보류**함. 해당 62개 표기에 관련된 기존 엄격한 원본 ID 118개 및 이번에 추가된 ID 90개는 삭제된 것이 아니라 **운영 후보로 미승격된 감사 자료**로만 남음. 판정 명세: `audits/youtube-b024-clear-nonindividual-and-identity-holds-20261020.json`.
